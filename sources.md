# Allowed sources

Only these five sources may be cited. A page outside them can be used to find an official URL, never as the cited source. UK material is not covered here and is always listed as a gap.

For every source: record the URL fetched, the page's own published, modified or last-updated date, and which date you used for each item.

## 1. European Commission AI Act pages

- Domains: `digital-strategy.ec.europa.eu` (AI Act page, library, news, FAQs) and `ai-act-service-desk.ec.europa.eu`.
- Primary page: the "regulatory framework AI" page (`https://digital-strategy.ec.europa.eu/en/policies/regulatory-framework-ai`).
- Minimum fetches: the primary page (timeline, "Policy and legislation" list, latest news), plus each in-window guideline, press release or FAQ it links.
- Search with `allowed_domains` restricted to the two domains above.

## 2. EUR-Lex

- Domain: `eur-lex.europa.eu`.
- Minimum fetches: any act the EC page links (for example an omnibus Official Journal reference). Attempt to open each; if it fails, say so and list it as a gap.

## 3. Colorado Attorney General AI rulemaking

- Page: `https://coag.gov/ai/` and the documents linked from it.
- Minimum fetches: the page, and the newest draft rules or notice it links. For large PDFs, save the file and Grep for definitions (consumer, consequential decision, conversational AI service) rather than reading everything. Record exactly what was read and what was only grepped.

## 4. CalPrivacy / CPPA

- Domains: `privacy.ca.gov` (newsroom: `https://privacy.ca.gov/about-us/newsroom/`) and `cppa.ca.gov`. Announcements moved to privacy.ca.gov from 26 Jan 2026.
- Minimum fetches: the newsroom list. Open only items that mention AI, ADMT, automated decisionmaking or risk assessments.

## 5. NIST

- Domain: `nist.gov`.
- Minimum fetches: the AI Risk Management Framework page and any in-window publication it lists.

## Known gaps to list every run

- UK coverage (no allowed source).
- Any primary text not opened (EUR-Lex act, guideline PDF, statute, draft rule).
- Owners left TBC.
- Any page that failed to load.
